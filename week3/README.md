# Week 3 – Agribusiness Performance Analysis using SQL

## Project Overview

This project focuses on analysing agribusiness performance using PostgreSQL. The analysis uses the maize production dataset prepared during Week 1 and structured into relational tables during Week 2.

## Business Scenario

A hypothetical agribusiness organization wants to evaluate maize production performance across countries and years.

## Dataset

Dataset: Maize Production by Country
Source: Our World in Data
Underlying Source: Food and Agriculture Organization (FAO)
Unit: Tonnes

## Tools Used

- PostgreSQL
- pgAdmin 4
- SQL
- Excel
- GitHub

## Objectives

- Analyse maize production performance
- Calculate production efficiency
- Calculate yield per acre
- Calculate cost per tonne
- Analyse country performance
- Analyse yearly production trends
- Analyse India's performance
- Generate business insights

## Key Performance Indicators

### Production Efficiency

Production tonnes divided by cultivated acres.

### Yield per Acre

Production tonnes divided by cultivated acres.

### Cost per Tonne

Operational cost divided by production tonnes.

## Simulated Variables

The original public dataset does not contain cultivated acreage or operational cost. Therefore, these variables were simulated solely for demonstrating agribusiness performance KPI calculations.

## SQL Analysis

The SQL script includes:

- Operational metrics table creation
- Data population
- Production efficiency analysis
- Yield analysis
- Cost per tonne
- Country performance
- Yearly production trends
- India performance
- Top producers
- Average production
- KPI summary
