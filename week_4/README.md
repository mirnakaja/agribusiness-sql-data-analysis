# Agribusiness Performance Analysis Using SQL

## 📌 Project Overview

This project focuses on analyzing maize production data across different countries and years using SQL and data visualization techniques.

The project was developed as part of the **SQL Data Analyst - Agribusiness Internship – Week 4** task. The main objective is to transform agricultural production data into meaningful analytical insights using **PostgreSQL, SQL, and Power BI**.

The analysis focuses on:

- Overall maize production performance
- Country-wise production comparison
- Year-wise production trends
- Top maize-producing countries
- India-specific production analysis
- Average production by country
- Highest and lowest production years
- Year-over-year production growth
- Data quality validation

---

## 🎯 Objectives

The main objectives of this project are:

1. Analyze maize production data using SQL.
2. Calculate overall production KPIs.
3. Compare maize production across countries.
4. Analyze production trends over time.
5. Examine India's maize production performance.
6. Identify the highest and lowest production years.
7. Calculate year-over-year production growth.
8. Validate the quality and consistency of the dataset.
9. Create meaningful visualizations using Power BI.
10. Generate business insights and recommendations from the analysis.
