# Dataset Information

## Dataset Name
Maize Production by Country

## Source
Our World in Data

## Underlying Data Source
Food and Agriculture Organization (FAO)

## Dataset Link
https://ourworldindata.org/grapher/maize-production

## Description
This dataset contains annual maize production data for countries and regions. Production is measured in tonnes and covers the period from 1961 to 2024.

The dataset is used in this project to demonstrate agricultural data acquisition, cleaning, validation, and preliminary transformation using PostgreSQL.
